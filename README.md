# 🤖 AI Document Classifier

An AI-powered Document Classification system that automatically analyzes documents and categorizes them into predefined classes using Machine Learning and Natural Language Processing (NLP).

## 🚀 Overview

The AI Document Classifier aims to simplify document management by automatically identifying document categories based on their textual content.

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/rajatcse9-a11y/AI_Document_Classifier.git
```

### 2. Navigate to the Project Directory

```bash
cd AI-Document-Classifier
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

## 🔄 Workflow

1. **Document Input:** Provide the document or its textual content.
2. **Text Preprocessing:** Clean and prepare the text for analysis.
3. **Feature Extraction:** Convert the text into a machine-readable representation.
4. **Model Prediction:** Use the trained AI model to predict the document category.
5. **Classification Output:** Display the predicted category.
